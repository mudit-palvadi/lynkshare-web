Limits

Web vs Android app limits.

The website is the fastest way to receive without installing anything. The Android app is the higher-limit client. The limit is the combined encrypted size of every file in one transfer, not the size of each file.

The numbers

ClientCloudDirect
Website10 MB10 MB
Android, standard15 MB20 MB
Android, unlocked30 MB50 MB

Every client allows at most 10 files. The service ceiling is 50 MB per transfer. The web has no unlock flow; the in-app unlock is an Android feature.

Why the web limit is lower

The website is designed to work without an install and without an account. Keeping the web transfer budget at 10 MB keeps the browser path predictable across phones, laptops and Safari. The Android app can use a larger budget because it controls the transfer lifecycle more tightly.

When the web is enough

  • A document, photo, PDF or small archive.
  • The receiver is on iPhone, iPad or a device without the app.
  • You want to receive without installing anything.
  • The sender is on a laptop and the file is small.

When to use the Android app

  • The file is larger than the web budget.
  • You want the Direct option for a live transfer.
  • You want the in-app unlock for a larger transfer.
  • You want the Android app's history and save-folder flow.
There is no iOS app. iPhone and iPad users receive through the browser, so the 10 MB web limit applies even if the sender is on Android.

Is LynkShare free?

Yes. There is no account, subscription or payment. The Android app contains ads to handle infrastructure costs, but the service itself is free to use.
