About

File transfer without the account.

LynkShare moves a file from one device to another without asking either person to create an account. The Android app and the browser receiver are two clients for the same encrypted transfer.

Why it exists

Sending one file should not require a sign-up form, a subscription, or installing the same app on every device. It also should not require uploading a readable copy to a server that can inspect it.

LynkShare encrypts the file on the sending device. The key travels in the link, not to the server. The service coordinates the transfer and stores ciphertext when a cloud session is used, but it does not receive the file key.

Cross-device by design

The same flow works between a phone and a laptop, two laptops, two phones, or a tablet and a computer. The sender can use the Android app or the web sender. The receiver can open the link in a browser or use the Android app.

There is no iOS app. iPhone and iPad users receive in Safari or Chrome through the web version, with the 10 MB web limit.

What LynkShare is not

  • It is not a backup service. Links and cloud sessions expire.
  • It is not anonymous. The service processes metadata and network addresses.
  • It is not a guarantee that an untrusted file is safe to open.
  • It is not a promise that a direct connection always works; cloud fallback exists for a reason.

Source and support

LynkShare is open source. The Android app and website are released under GPL-3.0. The project repository links the mobile, backend and web components.
